# Calculadora de Física com Trajetória

Uma ferramenta web interativa para simulação e visualização de trajetórias físicas. Permite que o utilizador defina constantes e fórmulas matemáticas (como velocidade, aceleração e tempo) para gerar gráficos de movimento em tempo real.

---

## 🚀 Funcionalidades

- **Interpretador de Fórmulas**: Escreva fórmulas de física "como no papel" (ex: `x = v * t`).
- **Visualização Dinâmica**: Gráfico em tempo real que desenha a trajetória do objeto de `t = 0` até o tempo final definido.
- **Cálculo de Variáveis**: Suporte para múltiplas variáveis (x, y, vx, vy, ax, ay).
- **Interface Intuitiva**: Painel dividido entre entrada de dados (fórmulas) e saída visual (gráfico e resultados numéricos).
- **Feedback Instantâneo**: Resultados detalhados para o instante `t` final.

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: HTML5, CSS3, JavaScript (Vanilla)
- **Motor Matemático**: [math.js](https://mathjs.org/) para avaliação de expressões.
- **Renderização**: HTML5 Canvas API para o desenho dos gráficos.

## 📦 Como Executar

Não é necessária instalação. Como o projeto é baseado em tecnologias web padrão, basta abrir o arquivo `index.html` em qualquer navegador moderno.

1. Clone o repositório:
   ```bash
   git clone https://github.com/betaodopedaco/fisica.git
   ```
2. Abra o arquivo `index.html` no seu navegador.
